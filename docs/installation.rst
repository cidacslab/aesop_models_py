Instalação
==========

Instale o pacote diretamente do PyPI:

.. code-block:: bash

   pip install aesop-models-py

Ou instale a versão em desenvolvimento (editable):

.. code-block:: bash

   git clone https://github.com/cidacslab/aesop_models_py.git
   cd aesop_models_py
   uv sync          # ou pip install -e .
